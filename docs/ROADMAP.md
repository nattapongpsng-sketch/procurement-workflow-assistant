| Milestone | เป้าหมาย | เกณฑ์สำเร็จ |
|---|---|---|
| **M0 Groundwork** ✅ | Rails + SQLite + Solid Queue, models, workflow YAML แรก, lib ภาษาไทย, DocumentGenerator + golden test, CI | ดู [PROGRESS.md](PROGRESS.md) |
| **M1 MVP** | ค้นหา → เลือก workflow → ขั้นตอน → สร้าง case → กรอก → generate เอกสารเสนออนุมัติ | คนที่ไม่รู้งานพัสดุสร้างรายงานขอซื้อขอจ้าง + รายงานผลการพิจารณาของ workflow AI ได้เองครบ โดยไม่ต้องพิมพ์ค่าที่คำนวณได้ |
| **M2 Workflow library + admin + auth** | builder สำหรับเจ้าหน้าที่พัสดุ, เพิ่ม workflow (AI > 50,000, AI นอก Recommended List, ซอฟต์แวร์ทั่วไป), ผู้ใช้และบทบาท, ข้อมูลหน่วยงาน | เพิ่ม workflow ใหม่ผ่านหน้า admin ได้โดยไม่แก้โค้ด และกำหนดสิทธิ์ตามบทบาทได้ |
| **M3 ติดตามสถานะและการอนุมัติ** | สถานะเรื่อง (ร่าง → ส่ง → อนุมัติ), บันทึกเลขที่/วันที่หนังสือ, ประวัติการเปลี่ยนแปลง, แจ้งเตือน | ผู้ขอซื้อและหัวหน้าเห็นว่าเรื่องอยู่ขั้นไหน และเอกสารทุกฉบับอ้างเลขที่ถูกต้อง |
| **M4 หลังอนุมัติ** | ยืมเงิน (ใบสำคัญจ่ายเงินยืม) → ซื้อ → ตรวจรับ → ล้างเงินยืม → รายงานผลการจัดหา AI | ทำครบวงจรของ workflow AI ได้ในระบบ พร้อมเอกสารแนบชุดยืมเงิน |
| **M5 ผู้ช่วย AI** | ร่างเหตุผล/วัตถุประสงค์, ดึงข้อมูลจากเอกสาร (เช่น หนังสือกรอบงบ, ภาพหน้าราคา), ตรวจทานความสอดคล้อง | ลดเวลากรอกและข้อผิดพลาดที่ตรวจพบก่อนส่ง โดยผู้ใช้ยืนยันทุกค่าที่ AI เสนอ |

## M1 รายละเอียด (ตาม 5 หน้าจอใน UI canvas)

1. **ค้นหา Workflow** — ผลค้นหาพร้อมเกรด A–D, workflow ที่ยังไม่เปิดแสดงเป็น "ต่อยอด"
2. **ช่วยเลือก Workflow** — 3 คำถาม → `EligibilityEvaluator` แสดงผ่าน/ไม่ผ่าน พร้อมเหตุผลและทางเลือก
3. **ขั้นตอนทั้งหมด** — มีแล้วแบบพื้นฐานใน M0; เพิ่มปุ่ม "สร้างเรื่องจาก Template"
4. **กรอกข้อมูลเรื่อง** — ฟอร์มจาก `FieldDefinition` แบ่งตาม `field_groups`, บันทึกร่างอัตโนมัติ, ค่าคำนวณแสดงสด, อัปโหลดภาพหน้าราคา, เลือกบุคคล/แหล่งงบ
5. **ตรวจทานและสร้างเอกสาร** — ความครบถ้วน, ความสอดคล้องระหว่างเอกสาร, generate ผ่าน Solid Queue, ดาวน์โหลด .docx / .zip
