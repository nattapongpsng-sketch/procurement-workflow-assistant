# Requirement ระบบจัดซื้อจัดจ้างวงเงินไม่เกิน 100,000 บาท

Nov 15, 2026 · @Nattapong

## ภาพรวม

ระบบนี้ให้ผู้ใช้กรอกข้อมูลการจัดซื้อเพียงครั้งเดียว แล้วสร้างเอกสารครบชุดตามแบบฟอร์มของหน่วยงาน พร้อมส่งขออนุมัติต่อเป็นลำดับขั้นได้ทันที ขอบเขตคือการจัดซื้อจัดจ้างวิธีเฉพาะเจาะจงที่มีวงเงินครั้งละไม่เกิน 100,000 บาท และการเบิกจ่ายที่ไม่ต้องจัดซื้อ เช่น ค่าสาธารณูปโภค

**ปัญหาที่แก้**

- ผู้ใช้ต้องพิมพ์ข้อมูลเดิมซ้ำในเอกสารหลายฉบับ เช่น รายการพัสดุ ราคา ผู้ขาย และเลขที่เอกสาร
- เลือกแบบฟอร์มหรืออ้างข้อระเบียบผิดตามวงเงินและประเภทพัสดุ
- ยอดเงินในเอกสารแต่ละฉบับไม่ตรงกัน และคำนวณ VAT ผิด
- ไม่รู้ว่าเรื่องค้างอยู่ที่ใคร และค้นเอกสารย้อนหลังยาก

**ในขอบเขต**

- จัดซื้อและจัดจ้าง วงเงินครั้งละไม่เกิน 100,000 บาท เช่น วัสดุ เครื่องมือ น้ำมันเชื้อเพลิง และจ้างซ่อม
- เบิกจ่ายค่าสาธารณูปโภคและค่าใช้จ่ายอื่นที่ไม่ผ่านกระบวนการจัดซื้อ
- สร้างเอกสาร ส่งขออนุมัติ ตรวจรับ ส่งเบิกจ่าย และเก็บประวัติ
- ส่งออกข้อมูลสำหรับรายงานผลและการประกาศผลตามที่ระเบียบกำหนด

**นอกขอบเขต (เฟสแรก)**

- การจัดซื้อที่วงเงินเกิน 100,000 บาท หรือใช้วิธีอื่นที่ไม่ใช่วิธีเฉพาะเจาะจง
- การเชื่อมต่ออัตโนมัติกับระบบ e-GP ระบบบัญชี หรือระบบ ERP ของหน่วยงาน
- การทำสัญญาเต็มรูปแบบและการบริหารสัญญา

**ตัวชี้วัดความสำเร็จ** (ตั้งค่าเป้าหมายหลังวัดค่าตั้งต้นของหน่วยงาน)

| ตัวชี้วัด                     | วิธีวัด                                            |
| ----------------------------- | -------------------------------------------------- |
| เวลาทำเอกสารต่อเรื่อง         | นับตั้งแต่เริ่มกรอกจนส่งขออนุมัติ เทียบกับการทำมือ |
| จำนวนเรื่องที่ถูกตีกลับให้แก้ | สัดส่วนเรื่องที่ถูกส่งกลับ ต่อเรื่องทั้งหมด        |
| ระยะเวลาอนุมัติ               | นับจากส่งเรื่องจนอนุมัติขั้นสุดท้าย                |
| ความถูกต้องของยอดเงิน         | จำนวนเอกสารที่ยอดเงินไม่ตรงกันต้องเป็น 0           |

## หลักเกณฑ์ที่ระบบต้องยึด

## ผู้ใช้และบทบาท

ผู้ใช้ 1 คนมีได้หลายบทบาท แต่ระบบต้องกันไม่ให้คนเดียวกันทำหน้าที่ที่ต้องแยกกันในเรื่องเดียว เช่น ผู้อนุมัติเป็นผู้ตรวจรับเอง (ยกเว้นกรณีที่ระเบียบอนุญาต เช่น ว 804)

| บทบาท                        | หน้าที่ในระบบ                                                   |
| ---------------------------- | --------------------------------------------------------------- |
| ผู้ขอซื้อ / ขอเบิก           | กรอกคำขอ แนบใบเสนอราคา ติดตามสถานะ แก้ไขเมื่อถูกส่งกลับ         |
| เจ้าหน้าที่พัสดุ             | ตรวจคำขอ เลือกผู้ขาย ออกเลขที่เอกสาร ส่งออกข้อมูล e-GP          |
| หัวหน้าเจ้าหน้าที่           | ตรวจทานและเสนอเรื่องต่อผู้มีอำนาจ                               |
| ผู้มีอำนาจอนุมัติ            | อนุมัติ ไม่อนุมัติ หรือส่งกลับให้แก้ ตามวงเงินที่ได้รับมอบอำนาจ |
| ผู้ตรวจรับพัสดุ / คณะกรรมการ | บันทึกผลตรวจรับ แนบรูปถ่ายและใบส่งของ                           |
| เจ้าหน้าที่การเงิน           | ตรวจเอกสารเบิกจ่าย บันทึกการจ่ายเงิน หักภาษี ณ ที่จ่าย          |
| Admin                        | ตั้งค่าหน่วยงาน ผู้ใช้ วงเงินอำนาจ แบบฟอร์ม และข้อมูลหลัก       |
| ผู้ตรวจสอบ (อ่านอย่างเดียว)  | ดูเอกสารและ audit log ย้อนหลัง                                  |

## กระบวนการหลัก

> **ร่าง — รอยืนยัน:** แผนภาพต้นฉบับ (จัดซื้อ 8 ขั้น และเบิกจ่ายตรง 2 ขั้น) ไม่ได้ติดมากับไฟล์ ตารางนี้เรียบเรียงจากหัวข้อบทบาทและตารางเอกสารในไฟล์นี้ ให้แก้ตามแผนภาพจริง

**เส้นทางจัดซื้อ / จัดจ้าง / เช่า (8 ขั้น)**

| ขั้น | งาน | ผู้ทำ | เอกสาร / ผลลัพธ์ |
| ---- | --- | ----- | ---------------- |
| 1 | กรอกคำขอ แนบใบเสนอราคาหรือหลักฐานราคา | ผู้ขอซื้อ | คำขอ (ระบบเลือกเส้นทางตามวงเงินและประเภท) |
| 2 | ตรวจคำขอ เลือกผู้ขาย ออกเลขที่เอกสาร | เจ้าหน้าที่พัสดุ | บันทึกรายงานขอซื้อขอจ้าง (พร้อมแต่งตั้งผู้ตรวจรับ) |
| 3 | ตรวจทานและเสนอเรื่อง | หัวหน้าเจ้าหน้าที่ | — |
| 4 | อนุมัติ / ไม่อนุมัติ / ส่งกลับ ตามวงเงินอำนาจ | ผู้มีอำนาจอนุมัติ | รายงานขอซื้อขอจ้างที่อนุมัติแล้ว |
| 5 | รายงานผลการพิจารณาและขออนุมัติสั่งซื้อสั่งจ้าง / ออกใบสั่งซื้อสั่งจ้าง (ถ้าเลือก) | เจ้าหน้าที่พัสดุ → ผู้มีอำนาจ | รายงานผลการพิจารณา (≤ 50,000: รายงานสรุปผลภายใน 5 วันทำการ), ใบสั่งซื้อ/จ้าง |
| 6 | ตรวจรับพัสดุ แนบใบส่งของ/ใบกำกับภาษี รูปถ่าย | ผู้ตรวจรับพัสดุ / คณะกรรมการ (≤ 50,000 ผู้จัดซื้อตรวจรับเองได้) | ใบตรวจรับพัสดุ |
| 7 | ขอเบิกเงิน / ขออนุมัติจ่าย | เจ้าหน้าที่พัสดุ | บันทึกขอเบิกเงิน, ใบปะหน้ารวมเอกสารแนบ |
| 8 | ตรวจเอกสาร จ่ายเงิน หักภาษี ณ ที่จ่าย | เจ้าหน้าที่การเงิน | หนังสือรับรองการหักภาษี ณ ที่จ่าย (ตามกรณี), บันทึก/ส่งออกข้อมูล e-GP |

**เส้นทางเบิกจ่ายตรง (2 ขั้น)** — เช่น ค่าไฟฟ้า น้ำประปา โทรศัพท์ อินเทอร์เน็ต

| ขั้น | งาน | ผู้ทำ | เอกสาร / ผลลัพธ์ |
| ---- | --- | ----- | ---------------- |
| 1 | ขอเบิก แนบใบแจ้งหนี้ | ผู้ขอเบิก | บันทึกขอเบิกเงิน / ขออนุมัติจ่าย, ใบปะหน้ารวมเอกสารแนบ |
| 2 | ตรวจเอกสารและจ่ายเงิน | เจ้าหน้าที่การเงิน | หนังสือรับรองการหักภาษี ณ ที่จ่าย (ตามกรณี) |

จำนวนขั้นอนุมัติก่อนจ่ายของเบิกจ่ายตรงยังต้องยืนยัน (ดูคำถามท้ายเอกสาร)

ทั้งสองเส้นทางมาบรรจบกันที่การเงิน คำขอที่ถูกส่งกลับจะกลับไปที่ผู้ขอพร้อมเหตุผล แล้วเริ่มตรวจใหม่ตั้งแต่ต้น ในเส้นทางไม่เกิน 50,000 บาท ผู้จัดซื้ออาจเป็นผู้ตรวจรับเองได้

## Milestone ที่แนะนำ

> **ร่าง — รอยืนยัน:** แผนภาพต้นฉบับไม่ได้ติดมากับไฟล์ ตารางนี้จัดจากระดับความสำคัญของ FR/NFR (รายละเอียดใน `docs/REPLAN.md`)

| Milestone | เนื้องาน | FR / NFR | สถานะ |
| --------- | -------- | -------- | ----- |
| M0 ฐานระบบ | Rails, แม่แบบเอกสาร .docx มีเวอร์ชัน, คำนวณยอดและตัวอักษรไทย, CI (ทำแล้วใน M0) + ปรับฐาน: PostgreSQL, PDF ฝังฟอนต์, ผู้ใช้/บทบาท, audit log, VAT และภาษีหัก ณ ที่จ่าย | NFR-01–06, FR-01, FR-04, FR-21, FR-28 | committed |
| M1 คำขอและเอกสาร | ทะเบียนผู้ขาย/พัสดุ/งบประมาณ, คำขอซื้อ/จ้าง/เช่า/เบิกจ่ายตรงหลายรายการ, เลือกเส้นทางตามวงเงิน, บล็อก > 100,000 และเตือนแบ่งซื้อ, แนบไฟล์, เลขที่เอกสารอัตโนมัติ, ตรวจความครบถ้วน | FR-03, FR-05–FR-13, FR-22, FR-23 | committed |

| M3 ตรวจรับ เบิกจ่าย รายงาน + นำร่อง | ตรวจรับ, ขอเบิก + ภาษีหัก ณ ที่จ่าย, เบิกจ่ายตรง, ค้นหา/ดาวน์โหลดทั้งชุด, สขร.1, ใช้จริงในหน่วยงานนำร่อง | FR-18–FR-20, FR-24, FR-25 | committed |
