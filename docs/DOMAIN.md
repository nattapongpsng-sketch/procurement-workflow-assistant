## 1. คำศัพท์และตัวย่อ

### 1.1 คำศัพท์งานพัสดุ

| คำ | ความหมาย (สำหรับคนไม่รู้งานพัสดุ) |
|---|---|
| รายงานขอซื้อขอจ้าง | บันทึกที่ผู้ขอซื้อเสนอผู้มีอำนาจ เพื่อขออนุมัติให้เริ่มจัดซื้อ ต้องมีหัวข้อ 1–7 ตามระเบียบ (เหตุผล รายละเอียด ราคากลาง วงเงิน กำหนดใช้ วิธีซื้อ เกณฑ์คัดเลือก) + ข้อเสนออื่น ๆ |
| รายงานผลการพิจารณาและอนุมัติสั่งซื้อสั่งจ้าง | บันทึกหลังได้ราคาแล้ว สรุปว่าจะซื้อจากใคร ราคาเท่าไร และขอให้ผู้มีอำนาจลงนามอนุมัติสั่งซื้อ |
| วิธีเฉพาะเจาะจง | วิธีจัดซื้อที่หน่วยงานเจรจาตกลงราคากับผู้ขายรายเดียวโดยตรง ใช้ได้เมื่อวงเงินไม่เกินที่กฎกระทรวงกำหนด (500,000 บาทตามเอกสาร) |
| ราคากลาง | ราคาอ้างอิงที่หน่วยงานหามาก่อนซื้อ (ในตัวอย่างใช้การสืบราคาจากท้องตลาด) วงเงินที่จะซื้อต้องไม่เกินราคากลาง ❓ |
| สืบราคา | หาราคาจากแหล่งที่ตรวจสอบได้ เช่น หน้าราคาบนเว็บไซต์ทางการ พร้อมเก็บหลักฐาน (ภาพหน้าจอ + วันที่) |
| วงเงินที่จะซื้อ | จำนวนเงินสูงสุดที่ขออนุมัติให้ใช้ ระบุแหล่งงบ บัญชี และศูนย์ต้นทุน |
| เกณฑ์ราคา | หลักเกณฑ์คัดเลือกข้อเสนอโดยดูราคาเป็นหลัก |
| ผู้ตรวจรับพัสดุ | ผู้ได้รับแต่งตั้ง (ในรายงานขอซื้อข้อ 8.2) ให้ตรวจว่าได้รับของครบถูกต้อง |
| เงินยืม / ใบสำคัญจ่ายเงินยืม | พนักงานยืมเงินจากกองการเงินไปจ่ายผู้ขายก่อน (เช่นซื้อ license ออนไลน์ด้วยบัตร) แล้วค่อยล้างเงินยืมด้วยใบเสร็จ |
| ล้างเงินยืม | ส่งหลักฐานการจ่ายจริงเพื่อปิดยอดเงินยืม ❓ (ไม่มีเอกสารตัวอย่าง) |
| Recommended List | รายชื่อ AI ที่ กฟภ. อนุญาตให้ใช้งาน/จัดหาได้ (23 รายการ หัวข้อ 6) |
| กรอบงบประมาณ | วงเงินที่หน่วยงานเจ้าของงบแจ้งให้ใช้ (ตัวอย่าง 1,350,000 บาทต่อทีม) |
| ศูนย์ต้นทุน / รหัสบัญชี | รหัสทางบัญชี (SAP) ที่ใช้ตัดงบ เช่น ศูนย์ต้นทุน Z201022090 บัญชี 53040010 |
| เลขที่หนังสือ | เลขทะเบียนส่งของหน่วยงาน รูปแบบ `<รหัสหน่วยงาน> <ลำดับ>/<ปี พ.ศ.>` เช่น `สชก.(บก-ท) 617/2569` ได้หลังลงทะเบียนส่งเรื่อง |
